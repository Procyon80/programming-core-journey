## 🧠 Core Principle: Time & Space Complexity (Big O)
**What is it?**
Big O notation is a way to describe how the runtime or space requirements of an algorithm grow as the input size grows.

- **O(1) - Constant Time**: The time taken is the same regardless of input size. (e.g., accessing an element in an array by index).
- **O(n) - Linear Time**: The time grows proportionally to the input size. (e.g., searching through a list for a value).
- **O(n²) - Quadratic Time**: Time grows quadratically. (e.g., nested loops).
