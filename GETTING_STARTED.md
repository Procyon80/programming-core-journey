# 🎯 Quick Start Guide

## Welcome! 👋

This is a **self-guided learning journey** focused on programming principles, not just syntax. You'll learn Python and SQL as tools to master universal concepts.

## Your First 30 Minutes

### Step 1: Start Here (5 min)
Read the overview: `/README.md` (you probably just did!)

### Step 2: Read Lesson 1 (15 min)
Open: `/curriculum/module-1/1-1-basics.md`

This introduces:
- How Python stores data (variables & types)
- How to get user input and show output
- How SQL retrieves data from databases

### Step 3: Try Exercise 1.1 (10 min)
1. Open: `/python/module-1/exercises/1-1-max-value/problem.md` - Read the problem
2. Open: `/python/module-1/exercises/1-1-max-value/starter.py` - See the template
3. Write your solution in the starter file
4. When done, compare with: `/python/module-1/exercises/1-1-max-value/solution.py`

## Tips for Success

### ✅ DO:
- Write code yourself before looking at solutions
- Understand *why* your code works, not just that it works
- Test edge cases (negative numbers, empty lists, etc.)
- Read the principle files—they're the "why"
- Type code instead of copy-pasting

### ❌ DON'T:
- Skip to solutions immediately
- Rush through principles
- Move to the next module before understanding current one
- Ignore Big O analysis—that's your competitive advantage

## When You're Stuck

1. **Re-read the problem** - Often you'll spot something you missed
2. **Test with simple examples** - Trace through by hand
3. **Look at similar problems** - See how others approached it
4. **Check the solution** - But only after trying hard
5. **Understand the solution** - Don't just memorize it
